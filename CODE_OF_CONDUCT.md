# Código de conduta

Este projeto adota o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/), que vale para issues, PRs, revisões e qualquer espaço do projeto.

Em resumo: trate todo mundo com respeito, critique o texto e não a pessoa, e não publique dado de ninguém sem permissão, seja de cliente, de corretora ou de quem participa.

Para reportar uma conduta que viole o código, escreva para **suporte@koter.app** com o assunto "Conduta: plugin". O reporte é tratado com sigilo.
