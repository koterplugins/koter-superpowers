# Changelog

All notable changes to this plugin, generated from the commit history. Versions follow [Semantic Versioning](https://semver.org/).

## [0.1.0](https://github.com/koterplugins/koter-superpowers/releases/tag/v0.1.0) (2026-11-18)

First release in this repository.

### Added

- 30 skills and 5 commands (`/introducao`, `/multicalculo`, `/especialistas`, `/superpoderes`, `/prova`) for setting up and running a brokerage on Koter through the Koter MCP server: Gestão, CRM, capture forms, KoterZap and chatbots, auto insurance multi-quote, data import and specialist agents.
- Contributing, security and code of conduct guides, the plugin architecture in `docs/ARQUITETURA.md`, and issue and pull request templates.
